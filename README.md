# Круглое счастье

Информационная система автоматизации сети ресторанов быстрого питания.
Платформа: 1С:Предприятие 8.5, файловая информационная база.
Учебная практика ПМ.02, ГБПОУ РХ «Хакасский политехнический колледж», гр. ИС(ТП)-41.

## Возможности
- справочники ресторанов, сотрудников, блюд, поставщиков, скидочных карт;
- роли и права (администратор, менеджер ресторана, повар, обслуживающий персонал);
- заказы: один открытый заказ на стол, закрытый заказ не изменяется, цена на дату заказа;
- рецептуры, обязательные остатки, поступление продуктов, долги перед поставщиками;
- печатная форма «Меню», отчёты (продажи официантов, топ клиентов, остатки продуктов, топ 10 блюд);
- настройки оформления сети (логотип, шрифт, цвет).

## Структура репозитория
| Путь | Содержимое |
|------|-----------|
| `src/` | конфигурация, выгруженная в файлы (Конфигуратор: Конфигурация → Выгрузить конфигурацию в файлы) |
| `features/` | сценарии Vanessa Automation |
| `docs/` | техническое задание, руководство системного программиста, руководство пользователя, документ по отладке, тестовые наборы и тестовый документ, описание тестирования официанта, словарь данных, диаграммы UML и ER (png), отчёт по практике |
| `dist/` | файл поставки `.cf` и выгрузка базы `.dt` (при необходимости) |

## Развёртывание
1. Создать пустую информационную базу (без конфигурации).
2. В Конфигураторе: Конфигурация → Загрузить конфигурацию из файлов (каталог `src/`) или из файла `.cf`.
3. Обновить конфигурацию базы данных (F7), выполнить проверку конфигурации.
4. Создать пользователей и назначить роли (см. руководство системного программиста в `docs/`).

## Автоматические тесты
Сценарии `features/*.feature` запускаются через Vanessa Automation (vanessa-automation.epf):
загрузить каталог `features`, настроить запуск TestClient на базу, нажать «Запустить сценарии».
Подробности: `docs/` и раздел 7 отчёта.
