# Круглое счастье (circlehappiness)

Информационная система автоматизации сети ресторанов быстрого питания.
Платформа: 1С:Предприятие 8.5, файловая информационная база.
Учебная практика ПМ.02, ГБПОУ РХ «Хакасский политехнический колледж», гр. ИС(ТП)-41.

## Возможности
- справочники ресторанов, сотрудников, блюд, поставщиков, скидочных карт;
- роли и права (администратор, менеджер ресторана, повар, обслуживающий персонал);
- заказы: один открытый заказ на стол, закрытый заказ не изменяется, цена на дату заказа;
- рецептуры, обязательные остатки, поступление продуктов, долги перед поставщиками;
- печатная форма «Меню», отчёты (продажи официантов, топ клиентов, остатки продуктов, топ 10 блюд);
- настройки оформления сети (логотип, шрифт, цвет).

## Состав репозитория
| Файлы | Содержимое |
|-------|-----------|
| `08.11.cf` | файл поставки конфигурации |
| `08.11.dt` | выгрузка информационной базы с тестовыми данными |
| `*.feature` | сценарии Vanessa Automation |
| `Техническое_задание_…`, `Руководство_системного_программиста_…`, `Руководство_пользователя_…` | документация |
| `Документ_по_отладке_…`, `Тестовый_документ_…`, `Тестовый_набор_XX_…`, `Описание_тестирования_официант_…` | отладка и тестирование |
| `Словарь_данных_….xlsx`, `диаграмма_*.png` | словарь данных, диаграммы UML и ER |
| `Отчет_УП_ПМ02_…` | отчёт по практике |

## Развёртывание
1. Создать пустую информационную базу.
2. Загрузить конфигурацию из `08.11.cf` (Конфигурация → Загрузить конфигурацию из файла) или базу из `08.11.dt` (Администрирование → Загрузить информационную базу).
3. Обновить конфигурацию базы данных (F7), выполнить проверку конфигурации.
4. Пользователи и роли: см. руководство системного программиста.

## Автоматические тесты
Сценарии `*.feature` загружаются в Vanessa Automation (vanessa-automation.epf). Запуск клиента тестирования требует полной версии платформы: на учебной версии менеджер тестирования базу запустить не может.
